# Phase 2: Password Spraying (T1110.003)

## Attack

Password spraying attempts common passwords against many accounts to stay under lockout thresholds. Real attempts were run against genuine AD accounts via `runas` and `net use`, generating EventID 4625 (failed logon).

## Two infrastructure findings worth noting

**Windows Server 2025 anti-spray throttling**: network-based spray attempts via `netexec` from Kali consistently timed out on any multi-account or wrong-password attempt, while single correct-credential connections succeeded instantly. This was identified as Windows Server 2025's built-in network-level anti-brute-force throttling, a legitimate OS security control, not a lab misconfiguration.

**Missing audit policy**: no 4625 events were being generated by any method (network or local) until `auditpol /get /subcategory:"Logon"` revealed that Logon failure auditing had never been enabled on the DC.
